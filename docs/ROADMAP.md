# ROADMAP — holdem-solver

> Правила этого файла важнее самого плана:
> 1. Приоритеты меняются ТОЛЬКО коммитом в этот файл. Молчаливых смен курса не существует.
> 2. Одна задача в работе одновременно.
> 3. Задача без проверяемого критерия готовности (DoD) в план не попадает.
> 4. Красный флаг снежного кома -> стоп -> разбор -> решение фиксируется здесь.
> 5. Каждая фаза завершается замерами в AI_LOG (время, память, узкое место).

Статусы: [ ] не начато | [->] в работе | [x] готово | [!] заблокировано

## Красные флаги снежного кома (стоп-сигналы)
1. Правим правку, которая чинила правку -> откат к зелёному, разбор.
2. Тест красный после 2-й попытки -> откат и думаем заново; 3-я попытка "наугад" запрещена.
3. Правка расползлась на 3+ файла вне задачи -> задача описана неверно -> к плану.
4. "Временно / потом перепишем" без записи в DECISIONS -> не допускать.
5. Агент оправдывает странный тест вместо разбора -> стоп.

## Сознательно НЕ входит в план
- Библиотека тысяч готовых спотов уровня GW.
- Цифровое совпадение с GW на каждом споте (его нет даже между коммерческими солверами).
- ICM-скорректированный постфлоп с точностью GW.
- Облачная ферма: всё считается локально.
